# poc_audit feedback

Session records written by the `learn-about-poc-audit` skill, one file per
session.

**These are not corpus.** They record what a reader asked, what they were
told, and what they made of it, in their own words. Nothing here states a
design position, and a participant's confusion is not a finding about the
design until the author decides it is. The corpus itself is `poc_audit/`, and
`poc_audit/AGENTS.md` indexes it.

Each record pins the corpus it describes by tree hash rather than commit hash,
because this branch has been rebased and commit hashes do not survive that.
A tree hash identifies the exact corpus content that was read.

Records are verbatim and attributed. Delivery through git is a proof of
concept convenience rather than part of the process, and is expected to be
replaced.
