# Frontend Development Guidelines

The canonical frontend guidance now lives in the **`frontend` skill** at
[`.claude/skills/frontend/SKILL.md`](../.claude/skills/frontend/SKILL.md).

Load that skill before reading, editing, or creating anything under `site/`.
It holds the FE1 to FE10 rule contract and the general frontend conventions.
Detailed material loads on demand from the skill's `references/` directory:

- [`references/patterns.md`](../.claude/skills/frontend/references/patterns.md)
  has correct/incorrect code examples for each FE rule.
- [`references/self-review.md`](../.claude/skills/frontend/references/self-review.md)
  is the deterministic FE1 to FE10 diff-audit to run before opening a PR.
- [`references/frontend-guide.md`](../.claude/skills/frontend/references/frontend-guide.md)
  has commands, TypeScript LSP navigation, components, styling, robustness,
  performance, workflow, and the full React rules.
