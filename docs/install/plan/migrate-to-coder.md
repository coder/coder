---
title: Migrate to Coder
---

These guides are for platform engineers who run developer environments on another platform and plan to move them to a self-hosted Coder deployment.
Each guide states the reader it assumes, maps the other platform's concepts to Coder in a table, and lists the migration steps in order, with links to the Coder docs for each step.

Each guide links to the other platform's public documentation for its own concepts.
Confirm details there, because other platforms change on their own schedule.

## Guides

- [Migrate from Ona (formerly Gitpod)](./migrate-from-ona.md): move an Ona Enterprise organization, including runners, projects, policies, and agents.
- [Migrate from Microsoft Dev Box](./migrate-from-dev-box.md): move dev centers, projects, and pools to Coder templates, with Windows workspaces on Azure.
