---
title: Community install methods
---

The methods on this page are contributed and maintained by the Coder community, not by Coder.
They aren't covered by Coder support, and they're separate from the [Community](../../reference/glossary.md#community) license tier.
Use them when Coder doesn't package an install method for your platform, and check the linked project to see how current it is.
Contributions are welcome.
