---
title: Install Coder as a web app
---

If you use Coder in a browser, you can install the dashboard or Coder Agents as a progressive web app (PWA).
You can launch the installed app from your device's app launcher or home screen instead of opening a browser tab.

## Install the dashboard

1. Open your Coder deployment in your browser.
2. Sign in to Coder.
3. Open a dashboard page outside `/agents`, such as **Workspaces**.
4. Follow the [instructions for your browser](#browser-instructions).

The dashboard app is named **Coder** and opens your deployment's home page.

## Install Coder Agents

1. Open `/agents` on your Coder deployment in your browser.
2. Sign in to Coder if prompted.
3. Follow the [instructions for your browser](#browser-instructions) while on `/agents`.

The Agents app is named **Coder Agents** (or **Agents**) and opens `/agents`.
The dashboard and Agents are separate installed apps, so you can install both.

## Browser instructions

Use the instructions for your browser after opening the page for the app you want to install.
Menu labels vary by browser version.

### Desktop Chrome or Edge

1. Select the install icon in the address bar, or select the web app installation option in the browser menu.
2. Confirm the installation when prompted.

### Android Chrome

1. Open Chrome's menu.
2. Select **Install app** or **Add to home screen**.
   If your menu shows **Install and create shortcut**, select **Install and create shortcut** > **Install** instead.
3. Follow the prompts to install the app.

### iOS or iPadOS Safari

1. Open Safari's **Share** menu.
2. Select **Add to Home Screen**.
3. If Safari offers **Open as Web App**, turn it on.
4. Select **Add**.

> [!NOTE]
> After a Coder upgrade, an installed app's name or icon may take a while to update because your browser caches the app manifest.
